# 沉浸：把学习元素融进世界

## 世界观＝学习结构
- 选一个能自然容纳"分科、主题、进度、薄弱点"的隐喻。公寓：楼层＝科目，房间＝主题，窗灯＝掌握，月亮＝复习入口，管理员猫＝陪伴者。
- 世界里的每个可见状态，都必须能翻译成一句学习上的话。翻译不出来的，就是装饰，要么删，要么让它承担意义。

## 角色（吉祥物）
- 角色是陪伴者，不是监督者。说话频率要设上限（例：主动开口间隔 ≥3 分钟、15 分钟最多 2 次；对答题的评论 ≥25 秒一次）。
- 体贴：不在 A 房间提 B 房间的弱项；考试倒计时不放在画面上，只偶尔由角色轻声提起（一天最多 2 次、间隔 3 小时、夜里不说）。
- 把学习功能放进角色的行为：长时间思考时给 3 段提示（30 秒／1 分／2 分），睡着时变成"梦话"气泡；只给方向，不给答案。
- 角色的画风、动作原理必须统一（同一个 Live2D 模板、同样的上色方式）；新角色先在试验场做，像"另一个世界的猫"就不能上线。

## 奖励
- 奖励只在真实进步时出现（房间达标亮灯、全对、连续学习）。
- 用有情感的素材：用户自家猫的实拍照片放进亮灯横幅，比通用插画更有动力。素材只用用户指定的，不混入别的照片。
- 奖励演出不能挡住文字，也不能太长（≈2 秒）。

## 入口与转场
- 入口用世界里的物体，靠光和动效提示"可以点"，不贴文字标签（文字显得碍眼）。
- 转场保持空间连续：点月亮 → 月亮飞到知识地图中心变成地图的中心；返回时反向飞回。
- 尊重"减少动态效果"设置。

## 视觉舒适
- 文字绝不重叠，不出现单个字孤零零换行；文字不压在图案上，必要时加描边。
- 光要淡，闪烁要么静止要么全体同相位；刺眼就是失败。
- 进度、跳转、滚动都要稳定：跳转停在固定标题栏正下方；长页面配可拖动的滚动条，显示当前章节名。
