# William の部屋 — 管理業務主任者試験の学習サイト

管理業務主任者試験の過去問を、猫の William と一緒に解いていく 1 ページのサイトです。

- **左：マンション＝問題の索引**　階＝分野（1F 適正化法 〜 8F その他）、**部屋＝同じテーマの相談のまとまり**（例：5F の 502号室＝集会・決議）。1つの階に 4〜8 室
  - 部屋の中の相談は 502-1、502-2 … と番号がつく。部屋分けは `src/data/rooms.json`
  - 建物は夜のマンションの絵（各階 8 つの窓、中央の柱の下に玄関）。部屋の少ない階の余った窓は「ほかの住人の部屋」で、最初から明かりがついている（明るさや色は窓ごとに違い、押せない）。番号のある窓が自分で明かりをつける部屋
  - 正解するたびに窓が少しずつ明るくなり、**部屋の相談の 8 割に正解すると明かりがつく**（全問正解で ★）。窓の下のバーは 金＝正解・赤＝まちがい
  - 窓を押すとその部屋に入る（まだの相談 → まちがえた相談の順に開く）。階の番号を押すと、その階のまだ明かりのない部屋へ
  - 部屋の相談を全部答えると、明かりがついたらカギ、足りなければ「あと何問」。「次の部屋へ」で隣の部屋に進む
  - 今の相談はアドレス（`#r06-12` など）にも残るので、再読み込みやブックマークで同じ相談から続けられる
- **右：相談票と William**　選択肢すべてに「管理人さん」の解説、ポイント・根拠条文・法改正の注意。William は正解でよろこび、まちがえると相談票に乗ってあくび
- **≡ 記録**　まちがえた／まだの相談の一覧、階ごとの正答率、進度リンク
- **スマホ**：① マンションの画面（階をえらんで窓をタップ）→ ② 相談票の画面（上に William、下に相談票）。「‹ マンション」で戻る
- 進度はブラウザに保存。進度リンク（下）を使うと自分のパソコンにも保存して、どの端末でも続きから解ける。↺ でリセット

## 収録している問題

- 過去問：令和元年度・令和3〜7年度（300問）。令和2年度は問題冊子が画像のため未収録。全問に選択肢ごとの解説つき
- オリジナル問題：`src/data/drills/`

## しくみ

- `william/tpl.html`：ページ本体（HTML・CSS・JavaScript。フレームワークなし）
- `william/build.py`：`src/data/`（過去問・オリジナル問題の JSON）と `william/assets/` の絵を埋め込んで `public/index.html` を作る
- `william/compose_bldg.py`：元のマンションの絵（`william/assets/bldg_orig.webp`、各階4窓）から、各階8窓のマンションの絵（`bldg.webp`）を作る
- `public/w/`：William の Live2D モデル。Live2D の公式サンプル Tororo のテクスチャだけを William の写真に合わせて塗り直したもので、形は元のまま
- クレジット：本コンテンツは Live2D Inc. が権利を有するサンプルデータ（Tororo）を使用しています（Live2D 無償提供マテリアル使用許諾契約）

## 手元で動かす

```bash
npm run build            # dist/ にサイトを作る（Python 3 だけで動く）
npm run progress-server  # http://localhost:8787/AdministrativeOperationsChiefExam/ で開ける
```

問題や解説の追加方法は [`docs/contributing.md`](docs/contributing.md) を参照してください。

## 公開

`main`（と作業ブランチ）に push すると `.github/workflows/deploy.yml` が GitHub Pages にデプロイします。以前の `/william/` の URL はトップに転送されます（進度リンクの `?u=` もそのまま）。

## 過去問の出典

一般社団法人マンション管理業協会「管理業務主任者試験問題」各年度（https://www.kanrikyo.or.jp/kanri/siken.html）。協会の「[過去問の使用について](https://www.kanrikyo.or.jp/kanri/pdf/kakomonshiyou.pdf)」により、教育目的での使用は無償・許諾不要で、出典の明記が必要です。各問題に出典を表示しています。解説はこのサイト独自のもので、協会とは関係ありません。

令和8年度試験は、2026年4月1日に施行された改正区分所有法などに基づいて出題されます。過去問は出題当時の法令に基づくため、改正点に関わる問題は現行法では正解が異なる場合があります（解説の「法改正の注意」を参照）。

## 進度リンク（自分のパソコンに進度を保存する）

GitHub Pages は記録を保存できないので、自分のパソコンで小さな「進度サーバー」を動かし、そこへ保存します。専用のリンク（`?u=ID`）で開けば、スマホでもパソコンでも同じ続きから解けます。

1. 進度サーバーを動かす（Node.js 18 以上。外部ライブラリは不要）

   ```bash
   npm run build   # 同じ Wi-Fi のスマホからサイトごと開きたいとき
   npm run progress-server
   ```

   記録は `server/data/<ID>.json` に保存されます（Git には入りません）。ポートは `PORT=9000 npm run progress-server` のように変えられます。

2. サイトの「≡ 記録」→「記録・進度リンク」に進度サーバーの URL を入れて「進度リンクを作る」を押すと、専用のリンクができます。

3. どこから開くか
   - **同じパソコン**：GitHub Pages のサイトに `api=http://localhost:8787` 付きのリンクで開けば、そのまま保存されます。
   - **同じ Wi-Fi のスマホ**：`http://<パソコンのIP>:8787/AdministrativeOperationsChiefExam/?u=<ID>` を開く（進度サーバーがサイトも配信します）。
   - **外出先のスマホから GitHub Pages で使う**：進度サーバーを https で外から見えるようにする必要があります（例：`cloudflared tunnel --url http://localhost:8787`）。出てきた https の URL を `api=` に入れます。

リンクの ID を知っている人は記録を見たり書き換えたりできるので、リンクはほかの人に教えないでください。パソコンの電源が切れている間はサーバーにつながりませんが、ブラウザの中には保存され、次につながったときに合わせます。
