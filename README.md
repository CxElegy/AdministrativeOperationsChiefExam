# William の部屋 — 管理業務主任者試験の学習サイト

管理業務主任者試験の過去問を、猫の William と一緒に解いていく 1 ページのサイトです。

- **左：マンション＝問題の索引**　階＝分野（1F 適正化法 〜 8F その他）、**部屋＝同じテーマの相談のまとまり**（例：5F の 502号室＝集会・決議）。1つの階に 4〜8 室
  - 部屋の中の相談は 502-1、502-2 … と番号がつく。部屋分けは `src/data/rooms.json`
  - 建物は夜のマンションの絵（各階 8 つの窓、中央の柱の下に玄関）。部屋は左から詰めて並び、部屋の少ない階の右側の余った窓は「ほかの住人の部屋」で、最初から明かりがついている（明るさや色は窓ごとに違い、押せない）。番号のある窓が自分で明かりをつける部屋
  - 正解するたびに窓が少しずつ明るくなり、**部屋の相談の 8 割に正解すると明かりがつく**（全問正解で ★）。窓の下のバーは 金＝正解・赤＝まちがい
  - 窓を押すとその部屋に入る（まだの相談 → まちがえた相談の順に開く）。階の番号を押すと、その階のまだ明かりのない部屋へ
  - 部屋の相談を全部答えると、明かりがついたらカギ、足りなければ「あと何問」。「次の部屋へ」で隣の部屋に進む
  - 今の相談はアドレス（`#r06-12` など）にも残るので、再読み込みやブックマークで同じ相談から続けられる
- **右：相談票と William**　選択肢すべてに「管理人さん」の解説、ポイント・根拠条文・法改正の注意。William は正解でよろこび、まちがえると相談票に乗ってあくび
- **≡ 記録**　まちがえた／まだの相談の一覧、階ごとの正答率、進度リンク
- **スマホ**：① マンションの画面（階をえらんで窓をタップ）→ ② 相談票の画面（上に William、下に相談票）。「‹ マンション」で戻る
- 進度はブラウザに保存。進度リンク（下）を使うと自分のパソコンにも保存して、どの端末でも続きから解ける。↺ でリセット

## 収録している問題

- 過去問：令和元年度・令和3〜7年度（300問）。令和2年度は問題冊子が画像のため未収録。全問に選択肢ごとの解説つき
- オリジナル問題：`src/data/drills/`

## しくみ

- `william/tpl.html`：ページ本体（HTML・CSS・JavaScript。フレームワークなし）
- `william/build.py`：`src/data/`（過去問・オリジナル問題の JSON）と `william/assets/` の絵を埋め込んで `public/index.html` を作る
- `william/compose_bldg.py`：元のマンションの絵（`william/assets/bldg_orig.webp`、各階4窓）から、各階8窓のマンションの絵（`bldg.webp`）を作る
- `public/w/`：William の Live2D モデル。Live2D の公式サンプル Tororo のテクスチャだけを William の写真に合わせて塗り直したもので、形は元のまま
- クレジット：本コンテンツは Live2D Inc. が権利を有するサンプルデータ（Tororo）を使用しています（Live2D 無償提供マテリアル使用許諾契約）

## 記録のリンク（サーバーなし。いちばん簡単）

答えた記録は、ページのアドレスの `?s=…` にそのまま入っています（問題ごとに選んだ番号を詰めたもの。200文字ほど）。

- 答えるたびにアドレス欄のリンクが新しくなります。「≡ 記録」→「記録・進度リンク」の「記録のリンク」からもコピーできます
- そのリンクをほかの端末で開くと、同じ記録の続きから解けます。ブックマークすれば保存にもなります
- リンクに入るのは、コピーした時点の記録です。別の端末で解いた分は、その端末のリンクを開けば戻ってきます

## 進度リンク（v13 の形のリンクをそのまま使い続ける）

記録は、自分のパソコンの進度サーバー（LocalServer）に、リンクの ID ごとに保存されます。

- リンクは `https://cxelegy.github.io/AdministrativeOperationsChiefExam/?u=<ID>&api=https%3A%2F%2Fhostels-graduated-ball-entering.trycloudflare.com&v=13` の形（v13 のリンク）に統一。`api=` は古いアドレスのままでよく、どの端末でも同じ ID なら同じ記録で、答えるたびに保存・1 秒ごとに読み込みます
- 開いたあともアドレス欄はこの形のまま。記録パネルでコピーできるリンクも同じ形です
- 進度サーバーの今のアドレス（トンネルの URL）は、このリポジトリの `tunnel.json` に書いてあり、サイトはそれを読んで接続します。つながらなくなったら `tunnel.json` を読み直して、新しいアドレスに切り替えます（`?api=` 付きの古いリンクも同じ）
- トンネルのアドレスが変わったら、パソコン側で次を実行して `tunnel.json` を更新します（LocalServer の「アドレスが変わったとき」の処理から呼ぶ）

  ```bash
  node server/update-tunnel-url.mjs https://xxxx.trycloudflare.com
  ```

  `GITHUB_TOKEN`（環境変数か `.env`）が必要です。GitHub の Fine-grained token で、このリポジトリの「Contents: Read and write」だけを許可してください。`tunnel.json` の更新ではサイトの再デプロイは起きません
- `npm run share`（このリポジトリの進度サーバー＋トンネル）も、`GITHUB_TOKEN` があれば起動時に `tunnel.json` を更新します

## 進度サーバーの動かし方（自分のパソコンに進度を保存する）

GitHub Pages は記録を保存できないので、自分のパソコンで小さな「進度サーバー」を動かし、そこへ保存します。同じ ID のリンク（`?u=ID&api=サーバーのアドレス`）で開けば、スマホでもパソコンでも同じ続きから解けます。

### ほかの端末からも使う（おすすめ）

1. パソコンに cloudflared を入れる（Cloudflare の無料トンネル。アカウント不要）
   - Windows：`winget install --id Cloudflare.cloudflared`
   - Mac：`brew install cloudflared`
2. このリポジトリのフォルダで次を実行する（Node.js 18 以上。ほかのライブラリは不要）

   ```bash
   npm run share
   ```

3. 画面に「進度リンク」（テスト1・テスト2）が出るので、それをスマホやほかのパソコンで開く

- 記録はパソコンの `server/data/<ID>.json` に保存されます（Git には入りません）。トンネルは通り道だけです
- このコマンドを動かしている間だけ、ほかの端末からつながります。止めている間もブラウザの中には保存され、次につながったときに合わせます
- 無料トンネルのアドレスは起動するたびに変わります。変わったら、新しく表示されたリンクで開き直してください
- 別の ID のリンクを作るときは `SHARE_IDS=好きなID npm run share`（ID は英数字12文字以上）

### 同じパソコンだけで使う

`npm run progress-server` を動かし、`api=http://localhost:8787` 付きのリンクで開きます。`localhost` は「その端末自身」のことなので、このリンクはほかの端末では記録を共有できません。

リンクの ID を知っている人は記録を見たり書き換えたりできるので、リンクはほかの人に教えないでください。
