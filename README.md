# マンション攻略 — 管理業務主任者試験の学習サイト

管理業務主任者試験の過去問で、マンションを1階から屋上（合格）まで攻略していく学習サイトです。

- **看板猫 William**：画面の案内役。正解すると喜び、メモ帳が空のときはお昼寝
- **攻略マップ**：マンションの階＝分野（1F 適正化法 〜 8F その他）、窓＝部屋＝5問のレッスン。部屋の相談に答えると明かりがつき、カギがもらえる
- **管理人さんの解説**：間違えた選択肢が「なぜ違うか」、正解の理由、根拠条文、令和8年4月施行の法改正の注意
- **メモ帳（復習）**：間違えた問題が 1日→3日→7日→14日→30日 の間隔で戻ってくる
- **総会（模試）**：1年分50問・2時間の本番形式（5問免除にも対応）、合格基準点で判定
- **記録**：階ごとの正答率、模試の履歴、連続学習日数（ブラウザに保存。書き出し・読み込み可）
- **ガイド・ノート**：試験の概要、分野ごとのノート

## 収録している問題

- 過去問：令和元年度・令和3〜7年度（300問）。令和2年度は問題冊子が画像のため未収録
- 解説：令和6年度・令和7年度の100問（選択肢ごとの解説つき）。ほかの年度は順次追加
- オリジナル問題：`src/data/drills/`

## 使っている技術

- [Astro](https://astro.build/) 7（静的サイト）。画面の動きは TypeScript（フレームワークなし）
- 過去問・解説は JSON、読み物は Markdown
- GitHub Pages に公開

## 手元で動かす

```bash
npm install
npm run dev
```

http://localhost:4321/AdministrativeOperationsChiefExam/ を開きます。

## 内容を追加する

解説、ノート、オリジナル問題、新しい年度の過去問の追加方法は [`src/content/guide/contributing.md`](src/content/guide/contributing.md)（サイト上の「コンテンツの追加方法」）を参照してください。

## 公開

`main` ブランチに push すると `.github/workflows/deploy.yml` が GitHub Pages にデプロイします。初回はリポジトリの **Settings → Pages → Source** を **GitHub Actions** にしてください。

## 過去問の出典

一般社団法人マンション管理業協会「管理業務主任者試験問題」各年度（https://www.kanrikyo.or.jp/kanri/siken.html）。協会の「[過去問の使用について](https://www.kanrikyo.or.jp/kanri/pdf/kakomonshiyou.pdf)」により、教育目的での使用は無償・許諾不要で、出典の明記が必要です。各問題に出典を表示しています。解説はこのサイト独自のもので、協会とは関係ありません。

令和8年度試験は、2026年4月1日に施行された改正区分所有法などに基づいて出題されます。過去問は出題当時の法令に基づくため、改正点に関わる問題は現行法では正解が異なる場合があります（解説の「法改正の注意」を参照）。

## William の部屋（新デザイン・試作）

`public/william/` にある 1 ページの試作版です。公開後は `/william/` で開けます（上部メニューの「William の部屋」からも行けます）。

- 左：マンションの階、右：相談票と William のキャットタワー。正解するたびに 1 階の窓に明かりがつきます。
- スマホでは「楼の画面」と「相談票＋William の画面」の 2 画面に分かれます。
- William は Live2D の公式サンプル Tororo のテクスチャだけを William の写真に合わせて塗り直したものです。形は元のままです。
- クレジット：本コンテンツは Live2D Inc. が権利を有するサンプルデータ（Tororo）を使用しています（Live2D 無償提供マテリアル使用許諾契約）。

## 進度リンク（自分のパソコンに進度を保存する）

GitHub Pages は記録を保存できないので、自分のパソコンで小さな「進度サーバー」を動かし、そこへ保存します。専用のリンク（`?u=ID`）で開けば、スマホでもパソコンでも同じ続きから解けます。

1. 進度サーバーを動かす（Node.js 18 以上。外部ライブラリは不要）

   ```bash
   npm run build   # 同じ Wi-Fi のスマホからサイトごと開きたいとき
   npm run progress-server
   ```

   記録は `server/data/<ID>.json` に保存されます（Git には入りません）。ポートは `PORT=9000 npm run progress-server` のように変えられます。

2. サイトの「記録」画面の「進度リンク」に進度サーバーの URL を入れて「進度リンクを作る」を押すと、専用のリンクができます。William の部屋（`/william/`）も同じリンクで進度が残ります。

3. どこから開くか
   - **同じパソコン**：GitHub Pages のサイトに `api=http://localhost:8787` 付きのリンクで開けば、そのまま保存されます。
   - **同じ Wi-Fi のスマホ**：`http://<パソコンのIP>:8787/AdministrativeOperationsChiefExam/?u=<ID>` を開く（進度サーバーがサイトも配信します）。
   - **外出先のスマホから GitHub Pages で使う**：進度サーバーを https で外から見えるようにする必要があります（例：`cloudflared tunnel --url http://localhost:8787`）。出てきた https の URL を `api=` に入れます。

リンクの ID を知っている人は記録を見たり書き換えたりできるので、リンクはほかの人に教えないでください。パソコンの電源が切れている間はサーバーにつながりませんが、ブラウザの中には保存され、次につながったときに合わせます。
