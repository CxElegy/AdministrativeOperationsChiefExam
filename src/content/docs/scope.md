このサイトでは、過去問を次の8つの分野に分けています（問題文の言葉から自動で振り分け、必要に応じて手で直しています）。各分野のノートには、年度ごとの出題数と問題番号の一覧があります。

| 分野 | 主な内容 | ノート |
| --- | --- | --- |
| 民法・借地借家法等 | 代理、時効、債務不履行、契約、相続、賃貸借 | [民法](../notes/minpo/) |
| 標準管理委託契約書 | 管理事務の内容、再委託、免責、契約の更新・解除 | [委託契約](../notes/itaku/) |
| 管理組合の会計・税務 | 仕訳、貸借対照表、収支報告、管理組合の税金 | [会計](../notes/kaikei/) |
| 建築・設備・維持修繕 | 構造、給排水、消防・電気・昇降機、劣化診断、長期修繕計画 | [建築設備](../notes/kenchiku/) |
| 区分所有法等 | 専有部分と共用部分、集会、規約、管理組合法人、建替え | [区分所有法](../notes/kubun/) |
| 標準管理規約 | 総会・理事会、役員、管理費等、使用細則 | [管理規約](../notes/kiyaku/) |
| マンション管理適正化法 | 管理業者の登録、管理業務主任者、重要事項説明、財産の分別管理 | [適正化法](../notes/tekiseika/) |
| その他の法令・実務 | 宅建業法、個人情報保護法、統計、その他 | [その他](../notes/sonota/) |

## おすすめの進め方

1. **まず1年分を本番モードで解く**：今の実力と、どの分野が弱いかを知る。
2. **分野ごとにノートを読み、その分野の過去問をまとめて解く**：[分野別演習](../practice/)で分野を1つだけ選ぶ。
3. **間違えた問題だけを繰り返す**：分野別演習で「前回間違えた問題」を選ぶ。全問正解になるまで。
4. **直前期は年度別に本番モード**：2時間で50問を解く練習。合格基準点＋2〜3問を目標に。

正答率は[学習記録](../record/)で分野ごとに確認できます。
