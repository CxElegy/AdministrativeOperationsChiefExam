# アナちゃん（playground）

ベースの絵は 1 枚：お手本の設定画の「正面で立つ猫」を そのまま使い、**毛の色だけ** アナちゃんの色（白＋こい あたたかい灰色）に変えたもの。
顔の見え方・顔のパーツの位置・体型・毛の質感は お手本のまま。

- `ref_front_cut.png`：設定画から 正面の猫を切り出して 4 倍に拡大し、背景を消したもの（820×1640）
- `make_ref.py`：オレンジと黒の ぶち → 灰色、首輪を消す、背景の残りを消す → `william/assets/ana_ref.webp`
- `tpl.html` の `loadAna` / `anaWarp` / `drawAna`：Live2D と同じ考え方で動かす。絵に 網目（21×41）を張り、頂点を パラメータで変形させる
  - 顔の向き X/Y（頭の輪郭より 顔のまん中が 多く動く＝回って見える）、頭のかたむき、呼吸、耳（おくれて動く・ぴくっ）、うなずき（食べる）
  - まばたき（目のすぐ上の毛の色の まぶたが 下りる）、口（もぐもぐ）、舌（ぺろっ）は 上に重ねて描く。位置は 網目と同じ式で変形するので ずれない
- 作り直し：`python3 william/ana/make_ref.py` → `npm run build`

## 試して分かったこと（1 枚の絵に Live2D の動きを載せる）

| 動き | できたか |
|---|---|
| 呼吸、頭のかたむき、顔の向き（左右・上下）、うなずき | できた（網目の変形） |
| 耳の動き | できた（網目の変形。大きく動かすと 絵がのびる） |
| まばたき、口、舌 | できた（上に重ねて描く） |
| 目玉が ポインターを追う | まだ（目が 絵に入っているので、目玉を 別の部品にする必要がある） |
| しっぽ | まだ（正面の絵に しっぽが写っていない。設定画の うしろ向きの絵から 部品を作る必要がある） |
| 大きく横を向く・歩く | できない（かくれている所の絵がない。設定画の 横向き・うしろ向きを 別の絵として切り替える方法になる） |
