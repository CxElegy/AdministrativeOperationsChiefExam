# アナちゃん（playground）

**大前提：William と アナちゃんは 同じ絵柄。** そのため、アナちゃんも William と同じ Tororo の Live2D モデルを そのまま使う。
変えるのは 毛の色・模様と、長毛の部分だけ。お手本の設定画（長毛の猫）は、長毛の ふくらみ方の参考にだけ使う。

- `tororo_parts.json`：Tororo の各部品の網目（テクスチャ上の位置 uv と、モデル上の位置 pos）。模様を モデル上の位置で決めるために使う
- `make_ana.py`：
  - `public/w/anabody.2048/`（体・足・耳・顔の土台。顔の部品は透明）と `public/w/ana.2048/`（顔の部品だけ）の 2 枚のテクスチャを作る
  - 模様は モデル上の位置の式（`face_mark` / `body_mark`）で決める。顔の土台にも まぶたにも 同じ式を使うので、色がつながる
  - 首輪・William の ぶち は消す。耳の外がわは アナちゃんの灰色
  - 長毛の部分は Tororo と同じ画法（線なし・なめらかな塗り・白い毛の影は うすいピンク）で別に描く：
    `ana_back.webp`（体のうしろの ふくらみ・ほおの毛）、`ana_mane.webp`（胸のたてがみ）、`ana_tail.webp`（太いしっぽ。Tororo と同じく 横へ）
- `tpl.html` の `loadAna` / `anaParams` / `drawAna`：
  - 重ねる順：しっぽ → うしろの毛 → 体のモデル → たてがみ → 顔の部品のモデル
  - 2 つのモデルに 同じパラメータを入れる（William と同じ Tororo のパラメータ：顔の向き・目・まばたき・耳・口・舌・呼吸）
  - しっぽは 網目を曲げて ゆらす
- 作り直し：`python3 william/ana/make_ana.py` → `npm run build`

## 耳の毛（スプライト）

- `ana_eartip.webp`：耳の先の 短い ふさ（リンクスティップ）。`ana_earhair.webp`：耳の中から 外へ のびる クリーム色の毛。
- どちらも 毎フレーム、体モデルの 耳メッシュ（`D_EAR_00` / `D_EAR_04`）の 頂点から 位置と角度を 計算して置く（`drawAna`）。耳が動いても ずれない。
- 重ねる画像は 小さく表示されるので、テクスチャは mipmap を ON にしている（細い毛が 点々に ならないように）。
- ほおの毛は `ana_back.webp` の中。耳の下から はじまり、下へ いくほど 広がる 灰色がかった こまかい房。
