# アナちゃん（playground）の作り方

William と同じ Live2D の公式サンプル **Tororo** を使い、テクスチャ（色の絵）だけをアナちゃん用に作る。モデルの形（moc3）は変えない。

## 1. Tororo はどう作られているか（分解した結果）

`tororo_meshes.json` に、モデルから取り出した部品の一覧を入れてある（部品の ID・描く順番・テクスチャ上のメッシュ）。

- **部品（描画単位）は 56 個**、テクスチャは 2048×2048 が 1 枚。うしろから順に重ねて描く。
  1. しっぽ（`D_TAIL_00/03`）
  2. うしろ足の先（`D_BODY_01/02`）、せなか・おしり（`D_BODY_00`）
  3. 前足・うしろ足（`D_ARM_*`：上・下・足先の 3 つずつ。ふだん用と、手を上げる用の 2 組）
  4. 胸（`D_CHEST_00`）
  5. 顔の土台（`D_FACE_00`）
  6. 口（`D_MOUTH_00〜06`：上あご・下あご・舌・歯・口元）、耳（`D_EAR_00〜07`：外側・内側・耳の毛）
  7. 目（`D_EYE_*`：白目・まぶた・まつげ、`D_EYE_BALL_*`：ひとみ・ハイライト）、まゆ・ひげ（`D_BROW_*`）、鼻（`D_NOSE_01`）
- **動き**は 31 個のパラメータ（頭の向き、目の開閉、口、舌、耳、しっぽ、呼吸、ほお、前足 など）でメッシュを変形させる。
- **大事な点：メッシュは絵にぴったり**。絵とメッシュのふちの間は 5〜20px しかない（部品の大きさは 500px くらい）。
  だから「テクスチャの絵の外側に長い毛を描き足す」ことはできない（メッシュの外は描かれない）。
- 目・鼻・口は顔の土台とは別の部品で、画面上の位置はモデルが決めている。テクスチャで動かすことはできない（色は変えられる）。

## 2. アナちゃんを入れる工程

1. **柄を塗る**（`gen_ana.py`）：William のテクスチャをもとに、部品ごとにアナちゃんの色にする。
   顔＝上と目のまわりは灰色・まん中に白い筋・口元は白／胸＝白（首輪は消す）／せなか＝灰色／しっぽ・耳の外側・まぶた＝灰色／目＝黄みどりがかった金色。
   → `ana_base_texture.png`
2. **長い毛を入れる**（`fluff_ana.py`）：顔・胸・せなかの 3 つの部品で、絵をメッシュの中で 0.86 倍に縮め、あいた外側の輪に毛の房を描く
   （房ごとに長さがちがう・先がとがる・下向きの房は長い。色はいちばん近い毛の色）。
   → `public/w/ana.2048/texture_00.png`
3. **モデルを大きく描く**（`tpl.html` の `drawAna`）：2 で縮めた分、モデル全体を 1/0.86 倍に描く。体の大きさは元のまま、まわりに毛の房が付く。
   房はメッシュの中にあるので、頭や体の動きと一緒に動く。長毛種なので横にも少し広く描く。
4. **性格の動き**（`anaParams`）：Tororo のパラメータで、まばたき・耳・しっぽ・食べる（顔を下げて口をもぐもぐ）・ぺろっ（舌）を付ける。

作り直すとき：`python3 william/ana/fluff_ana.py` → `npm run build`

## 3. 写真と比べて直したこと（1 回め）

作ったあと、正面で座っている写真と並べて、ちがう所を直した。

| ちがい | 直し方 |
|---|---|
| 顔の灰色が広すぎる（写真はほとんど白） | `gen_ana.py`：灰色は ひたいの上と目の上・外がわだけ。白い筋を広く |
| 目が大きく丸く、ふちが太い | 目を 7 割くらいの開きに。ふちの色をまわりの毛に近く。こはく色・たて長のひとみ |
| 耳の中がピンク | うすくして白い毛を描く |
| 灰色が冷たい・平ら | 茶色がかった灰色に。うすい しま（むら）を入れる |
| 胸が平らな白 | `fluff_ana.py`：房の影を何段も描く |
| 足が長く見える（写真は足先だけ見える） | 前足のひざ下の上 6 割を消して、胸の毛にかくれた形に。体は横に広く・たてに少し短く |
| しっぽが細い | Tororo のしっぽは透明にして、ふさふさのしっぽを `tpl.html` の `anaTail` で描く |

## 4. 写真と比べて直したこと（2 回め）

| ちがい | 直し方 |
|---|---|
| 体が細く小さい（写真は 横に大きく まるい） | 体（せなか・胸）・足先・頭を **べつべつの大きさで 3 回に分けて描く**。体だけ横に 1.75 倍。部品の不透明度を回ごとに切り替える（`drawAna` の `pass`） |
| 頭が横につぶれていた | 頭は たて横 同じ倍率で、首の上にのせる |
| 目のまわりが茶色い | 灰色を 茶色よりから ふつうの灰色に。目のふちを うすく |

注意：そのコマで最初にモデルを描くとき、モデルの更新が走って不透明度が元に戻る。先に 1 回 空描きしてから出し分ける。
手を上げる用の腕（`D_ARM_L_06〜08`、`D_ARM_R_00〜02`）は ふだん かくれている部品なので、描かない組に入れる。
